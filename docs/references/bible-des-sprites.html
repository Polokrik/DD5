Character Sprite Bible

Seven protagonist models built on a shared 64×96 logical grid. Each sprite has a character-specific silhouette, palette, idle motion, rare secondary motion and compact fight pose. The code is intentionally modular so Claude Code can transplant the drawing functions into the existing HTML renderer.

    Animation grammar

    Idle loop

    4–6 seconds. Two breathing frames are enough. Add one small asymmetric motion: shield shift, weapon weight, cloth, tail or focus glow.

    Rare action

    Trigger every 6–12 seconds, not every loop. Examples: beard adjustment, horn glint, checking a dagger, magical spark or dragon wing twitch.

    Guard pose

    Shift the centre of mass by 1–3 logical pixels. Preserve foot contact. Change the weapon angle with explicit frames rather than CSS rotation.

    Attack beat

    Anticipation, strike, impact and recovery. The preview compresses this to a readable pose; production scenes should use 4–8 explicit frames.
